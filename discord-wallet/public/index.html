Discord credentials

Connect this wallet to your private Discord. You'll need a bot you created at discord.com/developers.

Lock-down model. Even with the bot token, commands only execute if the caller matches your user ID, in your server, optionally in one channel. Three layers of "is this actually me?".

Encryption password

Encrypts the config + private keys at rest using AES-256-GCM · PBKDF2-SHA512 · 600k iterations. You'll type this on every bot startup.

enter a password
No recovery. If you lose this password, the config is unrecoverable. The seed phrase you'll see on the next step IS the wallet — write it down. The password only protects the file.

Wallet

A single BIP-39 mnemonic derives both your EVM (Ethereum, Base, Arbitrum, Polygon, BSC…) and Solana keypairs.

Back up your seed
